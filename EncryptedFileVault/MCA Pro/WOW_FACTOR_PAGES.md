## 🎨 Design System

### Colors Used
```
Blue:    #3b82f6 → #2563eb
Green:   #10b981 → #059669
Purple:  #8b5cf6 → #7c3aed
Orange:  #f59e0b → #d97706
Cyan:    #06b6d4 → #0891b2
Red:     #ef4444 → #dc2626
```

### Effects
```
Glass-morphism: backdrop-filter: blur(20px)
Gradients: linear-gradient(135deg, ...)
Shadows: 0 20px 60px rgba(...)
Hover: scale(1.05) + translateY(-10px)
```
